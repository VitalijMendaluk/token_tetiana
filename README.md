# Токенізована нерухомість — Квіз-лендінг

Односторінковий квіз-лендінг для реклами: збирає заявки на безкоштовний набір відеоуроків
про інвестиції в токенізовану нерухомість і надсилає їх у Telegram. Оптимізований під мобільний
(коректна висота в Safari, Chrome, вбудованому браузері Instagram/TikTok).

## Структура
```
index.html         # весь квіз (інтро → 3 питання → форма/відмова → подяка)
api/lead.js        # serverless-функція: заявка → Telegram
videos/            # video1.mp4, video2.mp4, video3.mp4 — відеовідгуки
.env.example       # шаблон змінних
```

## Логіка квіза
- **Питання 1** — що цікавить у темі нерухомості (сегментація).
- **Питання 2** — рівень досвіду в інвестиціях (кваліфікація).
- **Питання 3 — фільтр про гроші:**
  - «хочу серйозно вникати» → форма контакту;
  - «готовий почати з невеликої суми» → форма контакту;
  - «не готовий вкладати нічого» → екран «Упс…» (м'яка відмова, без подарунка).
- Кожне питання = окремий URL (`#q1`, `#q2`, `#q3`), працює системна кнопка «Назад», є прогрес-бар.
- Форма: ім'я + телефон з авто-визначенням коду країни по IP + згода (передвстановлена).
- Подія **Meta Pixel `Lead`** спрацьовує на відправку форми.
- Подарунок (набір відеоуроків) надсилається **особисто** після заявки — екран подяки веде в Telegram.

## Перед запуском (що замінити)
1. **Meta Pixel:** у `index.html` заміни `YOUR_PIXEL_ID` (2 місця) на свій Pixel ID.
2. **Telegram-нік:** на екрані подяки вже стоїть `@Aquarius9_9` (заміни, якщо треба інший).
3. **Відео:** у `videos/` лежать тимчасові відгуки — заміни на свої `video1.mp4`, `video2.mp4`, `video3.mp4`
   (за потреби відкоригуй підписи під відео в `index.html`).
4. **Telegram-бот:** створи `.env.local` на основі `.env.example` і встав `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

## Локальний запуск
```bash
npm i -g vercel
vercel dev
```
Змінні беруться з `.env.local`.
